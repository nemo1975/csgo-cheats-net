An HWID reset is the boring part of owning a CSGO cheat key. New PC, fresh Windows, same license. It is not a way to dodge a ban.

## When you actually need one

You built a new machine. You replaced a motherboard. You reinstalled Windows and the portal treats you as a new device. Those are the cases.

You got banned and you want a "clean" identity. That is not what this tool is for, and the [addon HWID spoofer](/products/csgo-cheats/) checkout page is equally not a VAC eraser.

## Portal first

Open the operator portal. If the reset button is available, use it once. Wait. Then download the current loader on the new PC. Do not run the old folder copied from the last drive.

If the button is grey, stop clicking it. Cooldowns exist so people do not farm resets. Email [support](/support/) with:

- Order email
- Why the hardware changed
- Windows version on the new box

## After it works

Your cloud configs may follow the license. If they do not, use the export file you should have saved. See [config presets](/blog/csgo-config-presets/).

## Sharing

Giving the loader to a friend is how keys get revoked. Each player needs their own plan. The [terms](/terms/) are explicit about this.
